Before you scrape: StockX publishes an official, authenticated Catalog/Order/Listing API at developer.stockx.com. If it covers your use case and you can get approved, it's the supported route. This scraper is for what the official API doesn't reach.
What was actually measured: an ordinary headless Chromium, no proxy, no 2Captcha key, cleared stockx.com's Cloudflare bot-management scripts and returned full data on every page tested. The infrastructure below buys volume, a specific exit country, or a consistent device identity — not passage through a wall that wasn't there. Full numbers in the README.

Risk management

Infrastructure, when you want it

CAPTCHA SOLVING

Broad detection, solves only when a page is actually gated — never just because a widget is present. Over --cdp-endpoint, wired into Captcha.setAutoSolve: detect, submit, solve, inject, all inside 2Captcha's own session.

SCRAPING BROWSER API

A remote browser session over CDP with its own proxy, fingerprint, and captcha auto-solve already bundled — one --cdp-endpoint flag.

FINGERPRINTS

Optional: pin a specific OS/browser/country fingerprint via the 2Captcha Fingerprint API for a locally-launched browser.

PROXIES

2captcha.com/proxy credentials in .env — rotated automatically, with per-exit failure tracking and masked logs.

Get started

# clone, install, configure
git clone https://github.com/2scraper/stockx-scraper.git
cd stockx-scraper && pip install -r requirements-playwright.txt && playwright install chromium
cp .env.example .env # optional — only needed for the paid products

# a category
python3 playwright_scraper.py --category sneakers --pages 3 --format json --out stockx_sneakers.json

# or a single product page
python3 playwright_scraper.py --url "https://stockx.com/air-jordan-4-retro-og-flight-club"
